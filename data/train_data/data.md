# 数据来源与处理说明

本研究使用公开的蛋白–配体分子动力学数据构建亲和力预测样本。数据及预训练资源如下。

| 名称                                                                                | 发布时间与来源                                                                                                        | 用途                                  |
| ----------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- | ------------------------------------- |
| [MISATO](https://zenodo.org/records/7711953)（2023 年，Zenodo 1.0.0）                | Siebenmorgen 等发布的蛋白–配体结构及分子动力学数据集；使用其中的`MD.hdf5` 和 `parameter_restart_files_MD.tar.gz` | 提供 MD 轨迹、蛋白/配体结构及拓扑信息 |
| [LP-PDBBind](https://github.com/THGLab/LP-PDBBind)（2023 年提出，基于 PDBBind 2020） | Li 等整理的蛋白–配体亲和力数据集；使用`LP_PDBBind.csv`                                                             | 匹配实验亲和力，仅采用 Ki/Kd 数据     |
| [dMaSIF](https://github.com/FreyrS/dMaSIF)（2020 年）                                | Sverrisson 等提出的蛋白分子表面表征方法；本项目中使用公开预训练权重                                                   | 提取蛋白表面特征，不提供亲和力标签    |

上述资源均引用其原始发布页面。

## 清洗与预处理

1. 轨迹与拓扑对应。以 MISATO 的复合物标识匹配 MD 轨迹和参数/拓扑文件，逐个读取复合物；拓扑仅在处理该复合物时解压使用。核对轨迹与拓扑的原子数量、顺序、元素及残基信息，排除不能可靠对应的条目。分析对象为蛋白和配体，不包括溶剂。
2. **配体识别与亲和力标签筛选。**本研究以蛋白与**小分子配体**的结合亲和力为预测对象，因此首先依据 MISATO 的配体原子标记、分子边界及配套拓扑确认配体身份；**MISATO 数据库中的蛋白–肽结合复合物直接排除**，无法可靠识别小分子配体的条目也不使用。随后以复合物的 **PDB ID** 在 LP-PDBBind 中查找对应实验记录：只有记录提供明确的 **Ki（抑制常数）或 Kd（解离常数）及其数值亲和力**时，才将该数值作为监督学习标签。没有对应记录、标签缺失或只有 IC50 等其他测量类型的复合物不纳入最终的带标签数据集；MD 轨迹本身不提供实验亲和力标签。
3. 口袋定义。以模拟参考帧中配体重原子的几何中心为圆心；蛋白残基只要有一个重原子距中心 **≤12 Å**，即保留该完整残基。同一模拟的所有帧沿用这一固定口袋。配体始终完整保留，后续 RMSD 计算使用蛋白口袋和配体的重原子。
4. 构象聚类。以口袋蛋白主链原子将各 MD 帧对齐至参考帧，再计算口袋蛋白与配体重原子的联合 RMSD；聚类时不重新拟合坐标。采用平均连接层次聚类，将模拟帧分为 **10 个候选状态**，每个状态选取簇内差异最小的实际帧作为代表。
5. **蛋白表面表示。**对每个代表帧的**完整蛋白**使用预训练 dMaSIF 提取表面点及 16 维特征，不将配体输入模型。随后仅保留距参考帧配体重原子几何中心 **≤12 Å** 的表面点，形成该状态的蛋白口袋表示。
6. 相近状态合并。比较状态 A 与 B 时，为 A 的表面点寻找 B 中空间最近的点；仅使用 **2 Å** 内且特征有效的对应点。匹配特征先作 L2 归一化，再以平均余弦距离衡量差异。按状态间距离阈值合并过于相近的状态，将被合并状态的帧数计入保留状态。最终状态概率为合并后的帧数除以该模拟总帧数，各状态概率之和为 1。

## 数据划分与泄漏防控

清洗后的样本以**蛋白–配体复合物**为单位，按 **8:1:1** 划分训练集、验证集和测试集。训练集用于模型拟合，验证集用于参数选择以及评估训练状态，测试集仅用于最终评估。同一复合物的所有轨迹帧及构象状态始终归入同一数据集；按复合物标识去重，避免重复样本跨集。预训练 dMaSIF 仅用于固定特征提取，不使用验证集或测试集的亲和力标签进行训练。

## 代码说明

以下三个脚本按 **候选状态生成 → 全局距离统计 → 状态合并及蛋白数据输出** 的顺序使用。命令均在包含三个脚本的项目根目录执行；处理需要可用的 CUDA GPU、预训练 dMaSIF 权重和 AmberTools 的 `cpptraj`，以及相应的 Python 依赖。三个脚本只处理蛋白状态数据，不生成亲和力标签或训练/验证/测试 manifest。

**当前处理好的训练、验证、测试用的原始数据**已上传至https://doi.org/10.5281/zenodo.23129260

### `stat.py`：生成候选状态和状态距离

输入：默认读取 `data/MD.hdf5`、`data/parameter_restart_files_MD.tar.gz` 和 `models/dMaSIF_search_3layer_12A_16dim`。

处理流程：顺序读取压缩归档，对每个复合物临时解压拓扑、从 HDF5 取得轨迹，并执行前述配体筛选、口袋定义、主链对齐和 10 簇联合 RMSD 聚类。每簇选择一个真实帧，用固定权重 dMaSIF 生成 12 Å 蛋白表面口袋的 16 维表示；随后计算 10 个候选状态两两之间的单向表面距离。无法满足空间匹配比例的状态对记为无穷大。

输出：每个成功处理的复合物在 `<cache>/<PDB ID>/` 下保存四个文件：`candidate_input.npy` 为逐表面点的 `[候选 state_id, 16 维特征]`；`populations.npy` 为各候选簇的帧数；`state_distance.npy` 为 10×10 单向距离矩阵；`representative_frames.npy` 为各簇代表帧的零基索引。分片目录另有 `skipped.tsv` 记录跳过的复合物及原因。已有完整缓存会被复用，脚本自身不绘制全局直方图。

使用示例（处理索引 0—2999；其他分片更换索引范围和 `--cache`）：

```bash
python stat.py --start-index 0 --end-index 3000 --cache stat_cache/shard_00000_03000
```

### `stat_aggregate.py`：汇总状态距离

输入与处理流程：默认从 `stat_cache/shard_*/*/state_distance.npy` 读取所有已完成分片，检查同一 PDB ID 不会在多个分片中重复出现，并汇集距离矩阵中所有有限、非对角的单向距离；已有缓存结构的距离同样计入统计。

输出：默认在 `stat_cache/summary/` 生成 `all_state_distances.npy`（汇总的距离数值）和 `state_distance_hist.png`（距离频率直方图）。`--bins` 默认为 40；`--hist-max` 默认为 0.35，只控制直方图展示范围，`all_state_distances.npy` 仍保存所有有限距离。观察分布后再确定状态合并阈值。

```bash
python stat_aggregate.py --cache-root stat_cache --output stat_cache/summary
```

### `protein_data.py`：合并状态并输出最终蛋白数据

输入与处理流程：从 `--cache`（默认 `stat_cache`）下读取各 `shard_*` 目录的 `candidate_input.npy`、`populations.npy` 和 `state_distance.npy`。`--cutoff` 为必填的状态距离阈值。每个复合物从帧数最多的候选状态开始保留；若某候选状态到已保留状态的单向距离低于阈值，则将其帧数并入最近的保留状态，不再保存其表面特征。剩余状态重新编号，并按合并后的帧数计算概率。

输出：默认在 `protein_output/proteins/<PDB ID>/` 生成 `input.npy`和 `state_probabilities.npy`。同一复合物的状态概率之和约为 1；最终状态数不超过 10。

以下 `0.10` **仅作命令格式示例**，实际数值应依据上述距离分布确定。当前项目中模型权重使用cutoff = 0.0（每个蛋白保留10个构象）获得的数据集训练得到。

```bash
python protein_data.py --cache stat_cache --output protein_output --cutoff 0.10
```
