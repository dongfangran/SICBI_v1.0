## 5. 代表帧、簇帧数与占比对应

### 5.1 代码依据

核查 `SICBI_proteindata/stat_5.py` 的 `process` 函数。

程序在遍历各簇时：

1. 使用 `frames = np.flatnonzero(labels == cluster)` 获取簇内帧。
2. 调用 `medoid_frame` 从簇内帧中选择代表帧。
3. 使用该代表帧生成表面特征。
4. 在同一个循环中依次保存特征、簇帧数和代表帧索引。
5. 按特征列表顺序将候选状态编号为 `i + 1`。

因此，依据当前代码：

- 候选状态 i 对应 `populations[i-1]`。
- 候选状态 i 对应 `representative_frames[i-1]`。
- 状态距离矩阵的对应行列也沿用该顺序。

这确认了当前代码中的数组对应规则，但不等于独立重算验证了历史代表帧选择。
